## 🌟 Overview & Mission

**SSC MASTER INDIA** is built to solve the fragmentation, ambiguity, and inaccuracy widespread across government job portals. Every exam under the Staff Selection Commission has distinct syllabi, marking schemes, qualifying tiers, post pay-scales, and physical/skill demands.

This platform provides:
1. **Independent, Versioned Exam Configurations** (`2024`, `2025`, `2026`, and `latest`) for every SSC exam.
2. **1,128 Bilingual Questions** (English + Hindi) with 4 options, full step-by-step explanations, difficulty levels, and exact source labels (**526 Verified TCS PYQs**).
3. **Specialized Interactive Labs**: Authentic CBT Mock Test Simulator, Practice Engine, Mental Math Speed Lab, Typing & DEST Lab, Audio Steno Dictation Lab, and JHT Translation Workshop.
4. **Candidate Decision Tools**: "Which SSC Exam Can I Apply For?" Eligibility Finder, Exam Comparison Matrix, Post & Department Explorer, "My Post Preference List" Builder with printable summary slips, and Ex-Servicemen (ESM) Reservation Center.
5. **Strict Copyright & Official Source Compliance**: 100% grounded in official notices (`https://ssc.gov.in`), zero pirated PDFs, and legitimate publisher catalog mappings.

## 🎯 Question Bank & Data Integrity

The question bank is validated through automated test pipelines:
- **Total Questions**: **1,128 unique bilingual questions** (exceeds the 1,000 question benchmark).
- **Verified TCS PYQs**: **526 questions** directly mapped to verified past shift papers (CGL 2023-2024, CHSL 2023, MTS 2023, GD 2024, CPO 2023, JE 2023).
- **Transparency Source Labels**:
  - `VERIFIED PYQ`: Sourced directly from official TCS CBT answer keys.
  - `PYQ-STYLE`: Crafted to simulate modern TCS exam question traps and patterns.
  - `ORIGINAL`: Concept-strengthening diagnostic questions.
- **Subjects Covered**: Quantitative Aptitude, General Intelligence & Reasoning, English Comprehension, General Awareness, Computer Knowledge, General Hindi, Civil Engineering, Electrical Engineering, and Translation.

## ⚡ Interactive Practice & Specialized Labs

1. **Authentic CBT Mock Test Simulator** (`/mock-tests`):
   - Exact SSC TCS CBT layout with interactive timer, section switcher, and 5-state question palette (Not Visited, Not Answered, Answered, Marked for Review, Answered & Marked).
   - Real negative marking calculation (0.50 for CGL Tier-I, 0.25 for GD/MTS, 1.00 for CGL Tier-II).
   - Instant scorecard, accuracy percentage, time spent per section, and answer key breakdown.

2. **Practice Engine** (`/practice`):
   - Configurable test sizes (10, 20, 50, 100 questions).
   - Filter by exam, subject, difficulty, and source type.
   - Immediate answer review with one-click bookmarking and error logging.

3. **Mental Math Speed Lab** (`/speed-lab`):
   - 60-second rapid-fire drills for Squares ($11^2$ to $50^2$), Cubes ($2^3$ to $25^3$), Multiplication Tables (12 to 30), and Rapid Addition.

4. **Typing & DEST Simulator** (`/typing-lab`):
   - Real-time gross WPM, net WPM, keystrokes (KDPH), and error percentage.
   - English (35 WPM / 10,500 KDPH) & Hindi Inscript / KrutiDev (30 WPM / 9,000 KDPH).
   - Optional toggle for SSC Strict Mode (Backspace disabled).

5. **Stenography Dictation Lab** (`/steno-lab`):
   - Web Speech Synthesis audio dictation at official speeds: **80 WPM** (Grade D) and **100 WPM** (Grade C).
   - Interactive transcription editor with real-time error percentage and word omission calculation.

6. **JHT Translation Workshop** (`/translation-lab`):
   - English-to-Hindi and Hindi-to-English translation passages.
   - Official administrative terminology glossary (Rajbhasha vocabulary).

7. **Physical Fitness (PET/PST) Tracker** (`/physical-test`):
   - Official height, chest expansion, and running criteria for SSC GD, SSC CPO (Delhi Police SI), and MTS Havaldar.
   - Gender-specific and regional hill-tribe relaxation parameters.

8. **Decision & Preparation Tools**:
   - **Eligibility Finder**: Age, category, qualification, and physical attribute calculator.
   - **Post & Department Explorer**: Pay Levels 1–8, Grade Pay 1800 to 4600/4800, job responsibilities, postings, and promotion ladders.
   - **My Post Preference List**: Drag/reorder candidate preference list with printable slip for SSC Option-cum-Preference form filling.
   - **Ex-Servicemen (ESM) Center**: Reservation quotas, fee exemptions, age deductions, and pension protection guidelines.
   - **Formula Book**: Quant formulas, arithmetic shortcuts, and geometry theorems.
   - **Flashcards**: Active recall flashcards with spaced repetition status.
   - **Error Notebook**: Dedicated mistake categorization (conceptual, calculation, misread, time pressure).

## 🚀 Getting Started

### Prerequisites
- Node.js `v18.0.0` or higher
- npm `v9.0.0` or higher

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/raghavendra-exp/ssc-master-india.git
cd ssc-master-india

# Install dependencies
npm install

# Validate data integrity & question count
npm run validate:data

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle to dist/
npm run build

# Preview production build locally
npm run preview
```
